Smart Greenhouse Automation System

Personal project

ESP32 · MQTT · Google Blockly · DHT22 · soil moisture · reservoir level · OLED

  • No-code IoT rule engine that monitors greenhouse conditions and automates operations. Rules are built by dragging Blockly blocks, not writing code.
  • Reads temperature, humidity, soil moisture and reservoir level, with live status on an OLED display.
  • Controls a water pump and ventilation from the rules. Rules are validated, run in real time, and can be saved and loaded as profiles.
  • Data flows from sensors over MQTT to a dashboard, then through the Blockly rule engine to the actuators.

Add: the dashboard you used, one example rule with thresholds, and what happens if a sensor stops reporting.

ESP32-CAM Smart Surveillance Robot

Personal project

ESP32-CAM · PIR · ultrasonic · Telegram Bot API · L298N

  • Camera robot that captures images and sends alerts to Telegram in real time.
  • PIR sensor for human detection and an ultrasonic sensor for distance, with the captured image and distance shown on a web page.
  • Live Wi-Fi video from an ESP web server, with forward, back, left, right and stop controls in the browser.
  • Wireless motor control through an L298N driver for remote monitoring.
  • Everything runs in a single firmware image on one ESP32-CAM, with no second microcontroller.

IR Obstacle Detection with Email Alerts

Personal project

Arduino Uno · NodeMCU · IR sensors · LCD · SMTP

  • IR sensors detect an obstacle, and an Arduino Uno with a NodeMCU handle the detection and the alert.
  • The NodeMCU sends an email alert over SMTP so the system can be monitored remotely.
  • Built on a single board with an LCD display, so the hardware is easy to see and demonstrate.
