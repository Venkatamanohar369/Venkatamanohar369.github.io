ESP32-CAM Smart Surveillance Robot

Personal projectFeatured

ESP32-CAM, PIR, ultrasonic, Telegram Bot API, L298N

Problem
Add live video, alerts and drive control to a low-cost board without a second microcontroller.
Built
A surveillance robot where one ESP32-CAM streams video over Wi-Fi, sends Telegram alerts and drives the motors through an L298N.
Outcome
Live stream, image capture, human detection, distance measurement and wireless control, all from a single firmware image.
Technical details
  • Captures images and sends alerts to Telegram in real time.
  • PIR sensor for human detection and an ultrasonic sensor for distance, with the captured image and distance shown on a web page.
  • Live Wi-Fi video from an ESP web server, with forward, back, left, right and stop controls in the browser.
  • Wireless motor control through an L298N driver for remote monitoring.

Smart Greenhouse Automation System

Personal project

ESP32, MQTT, Google Blockly, DHT22, soil moisture, reservoir level, OLED

Problem
Growers should be able to change automation rules without touching firmware.
Built
A no-code IoT rule engine on ESP32 and MQTT, with rules built from drag-and-drop Google Blockly blocks.
Outcome
Rules are validated, run in real time and can be saved and loaded as profiles to control a water pump and ventilation.
Technical details
  • Reads temperature, humidity, soil moisture and reservoir level, with live status on an OLED display.
  • Controls a water pump and ventilation from the rules.
  • Data flows from sensors over MQTT to a dashboard, then through the Blockly rule engine to the actuators.

GitHub repo

Smart Factory Monitoring

Internship project at Emertxe, Mar–Apr 2026

Embedded C, PicsimLab, MQTT, ThingsBoard, RPC

Problem
See live data from several factory nodes and control them remotely.
Built
A simulated multi-node system in PicsimLab publishing MQTT telemetry to a ThingsBoard dashboard, with RPC commands sent back down to the nodes.
Outcome
Dashboard-to-node control with no manual steps, and modular embedded C firmware that cut debugging effort across nodes.
Technical details
  • Multi-node monitoring simulated in PicsimLab, with nodes publishing telemetry over MQTT.
  • Live ThingsBoard dashboard showing data from every node in real time.
  • Automated device control from the dashboard using RPC commands.
  • Firmware structured into reusable modules following SDLC practices.

IR Obstacle Detection with Email Alerts

Personal project

Arduino Uno, NodeMCU, IR sensors, LCD, SMTP

Problem
Get a remote notification when an obstacle is detected.
Built
IR sensors with an Arduino Uno and a NodeMCU, with status shown on an LCD on a single demo board.
Outcome
The NodeMCU sends an email alert over SMTP, so the system can be monitored remotely.
Technical details
  • IR sensors detect an obstacle, and the Arduino Uno and NodeMCU handle detection and the alert.
  • Email alerts are sent over SMTP for remote monitoring.
  • Built on a single board with an LCD, so the hardware is easy to see and demonstrate.
